## Featured Project

### CourseLens AI

An AI-powered course tutor built to help students learn directly from their course materials.

- Upload PDFs and chat with course content
- Get RAG-based answers with citations
- Generate quizzes from study materials
- Track weak areas over time
- Built with a **FastAPI** backend and **Streamlit** frontend

**Tech:** Python, FastAPI, Streamlit, OpenAI API, RAG, SQL, Docker
